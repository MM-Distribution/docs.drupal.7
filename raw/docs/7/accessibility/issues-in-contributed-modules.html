Issues in contributed modules

Last updated on
23 April 2023

This is documentation for Drupal 7, which is no longer supported. Learn more and find resources for Drupal 7 sites

Please note that this was the Drupal 7 best practice. For current best practices see the Accessibility Handbook.

Accessibility issues aren't simple and are based on an evolving standard. This is a list of reported issues that will help to improve the accessibility of Drupal sites using these modules and themes. This is not a comprehensive list; it will change over time.

The Contribute to accessibility page provides a list of reported Drupal core accessibility issues.

For more general discussions about Drupal accessibility, see the Accessibility Group and related Documentation.

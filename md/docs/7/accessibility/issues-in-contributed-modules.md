# Issues in contributed modules

**Please note that this was the Drupal 7 best practice. For current best practices see the [Accessibility Handbook](https://www.drupal.org/docs/accessibility/drupal-accessibility-features).**

Accessibility issues aren't simple and are based on an evolving standard. This is a list of reported issues that will help to improve the accessibility of Drupal sites using these modules and themes. This is not a comprehensive list; it will change over time.

The [Contribute to accessibility](https://www.drupal.org/node/364629) page provides a list of reported Drupal core accessibility issues.

For more general discussions about Drupal accessibility, see the [Accessibility Group](http://groups.drupal.org/accessibility) and related [Documentation](http://drupal.org/node/394094).

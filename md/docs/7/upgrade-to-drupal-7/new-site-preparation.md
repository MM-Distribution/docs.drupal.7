# New Site Preparation

The upgrade process described on the next page assumes that you have already downloaded Drupal 7 core and the contributed modules of the new version that you will need for your site. The following steps will help you prepare these files for the actual upgrade.

1.  [Download the target Drupal version](http://drupal.org/download) (Drupal 7)
2.  Download target Drupal versions of the contributed modules you will need for your site.
3.  Prepare the target Drupal versions of your customized modules or customized themes.  
    Customization documentation can be found at: [The Drupal Module Developer's Guide](http://drupal.org/developing/modules).
4.  Create a test site location to practice your upgrade to Drupal 7, check the content after the test upgrade to be sure it worked.

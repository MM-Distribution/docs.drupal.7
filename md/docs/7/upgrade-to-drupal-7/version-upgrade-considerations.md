# Version upgrade considerations

Here are some general considerations to take into account when upgrading to Drupal 7.

1.  See the instructions in the UPGRADE.txt file of the Drupal download and in the [upgrade to Drupal 7 section of the handbook](/upgrade).
2.  Read the [Best Practices on test sites](/node/22282) and don't do it first on your live site.
3.  Make sure that all the contrib modules you are using have an upgrade path to Drupal 7 or you are willing to upgrade them yourself or abandon them.
4.  Make sure you read and follow any instructions regarding upgrading any permissions modules you are using. Many have specific steps you need to take before starting your upgrade.

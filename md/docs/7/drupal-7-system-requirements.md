# Drupal 7 system requirements

This guide covers detailed system requirements for a Drupal 7 installation.

## [Overview](/docs/7/system-requirements/overview)

To install and run Drupal your web server must meet certain minimum requirements.

## [Web server](/docs/7/system-requirements/web-server)

Drupal works on any web server with PHP support.

## [Database server](/docs/7/system-requirements/database-server)

Recommended: MySQL (or an equivalent such as MariaDB or Percona Server)

## [PHP requirements for Drupal 7](/docs/7/system-requirements/php-requirements-for-drupal-7)

Detailed information regarding the PHP requirements for Drupal 7

## [What is PDO?](/docs/7/system-requirements/what-is-pdo)

PDO is an acronym for PHP Data Objects. PDO is a lean, consistent way to access databases. This means developers can write portable code

## [Browser requirements](/docs/7/system-requirements/browser-requirements)

Websites built using just Drupal 7 core are compatible with, and fully functional, in all modern browsers that support CSS and JavaScript.

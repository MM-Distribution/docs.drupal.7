# Responsive Design + Server-side Components (RESS)

RESS: Responsive Design + Server-side Components: RESS combines responsive layouts with server side component (not full page) optimization. So a single set of page templates defines an entire web site for all devices but key components within that site have device-class-specific implementations that are rendered on the server side.

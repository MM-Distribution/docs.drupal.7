# Comparison of contributed modules

**Note: For Drupal 8, see [Drupal 8: Comparison of Contributed Modules](/docs/8/comparison-of-contributed-modules). The information below pertains to Drupal 7-.**

This section contains overviews of different groups of contributed modules that carry out similar tasks. These overviews can be very useful if you are evaluating modules to meet a certain requirement and cannot distinguish the differences between them.

Note that some contributed modules change rapidly, sometimes within weeks or months of being reviewed, therefore comparisons may not reflect the current state of modules. For an up to date module description find each module's [project page](http://drupal.org/project/Modules).

If you spot errors, or find yourself reviewing a group of similar modules that have not been covered in this section, please [contribute corrections and additions](http://drupal.org/contribute/documentation).

Please also view the [Similar Module Review](http://groups.drupal.org/similar-module-review) group, which offers many comparisons of modules that offer similar functionality.

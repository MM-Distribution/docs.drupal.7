# Comparison of Image-handling modules

There are hundreds of threads on drupal.org illustrating the complexity and confusion the new Drupal user experiences in trying to make an informed decision on what image-handling modules to choose to fit the needs of a given site. [1](/node/9957) [2](/node/3227) [3](/node/75603) [4](/node/107622) [5](/node/110203) [6](/node/166278) [7](/node/207754) [8](/node/218867) [9](/node/297160) [10](http://groups.drupal.org/node/10712) [11](http://groups.drupal.org/node/12797) [12](http://groups.drupal.org/node/5328)

So, in response to the many requests for a good overview of this topic in the Handbook - here we go!

There are [dozens of ways to handle images in Drupal](http://www.google.com/search?q=site%3Ahttp%3A%2F%2Fdrupal.org+image+OR+pictures), and very little in Drupal's *core* code to even support the various *contributed* modules ([definitions](/History-mission-and-community)), other than [(currently fairly basic) file handling routines.](/node/325525)

There is no "one right" image-handling module that fits all the different sites' needs. Some of the variables that need to be taken into account follow.

Please note that this picture will change signficantly with the release of Drupal 7 which will integrate image handling into Drupal core.

# Multi-site on Mac

To get multi-sites working on apache on a Mac, see ["HowTo: Configure your local workstation to serve multiple sites using Drupal's multisite configurations and Apache's VirtualHost"](http://drupal.org/node/238805).

In addition, most instructions valid for Linux is valid for Mac OS X. And the general multi-site docs are mostly written by Linux users.

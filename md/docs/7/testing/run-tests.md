# Running automated tests

Once you have completed the [Setup and configuration](http://drupal.org/node/519364) (enabled the Testing module) you are ready to run some tests.

1.  Visit */admin/config/development/testing* where you will find a listing of the all the tests, grouped by what they test. Access to this page requires a user who has the "Administer tests" permission.
2.  Select the tests or group of tests you wish to run.
3.  Press the *Run tests* button at the bottom of the page.

Once the tests have finished the results will be displayed and any failing tests will have the results expanded.

Also look to run tests [through command-line](/node/645286 "Running Tests Through command-line")

# Testing Reference

The following resources provide some additional information on testing with Drupal. Please also read the sub-pages with more details.

- Drupal 7 core tests - the framework was developed alongside them.
- [SimpleTest Drupal Module](/project/simpletest)
- [Unit Testing Group](http://groups.drupal.org/unit-testing)
- [Full doxygen documentation](http://cwgordon.com/simpletest/doxygen/2008-june/index.html)
- [Drupalcon Paris 2009 SimpleTest presentation](/files/drupalcon-paris-2009-simpletest_0.pdf)

Information about previous versions of SimpleTest. These articles make use of hooks, methods, and functions that do not exist in current versions of SimpleTest.

- [Lullabot: An Introduction to Unit Testing](http://www.lullabot.com/articles/introduction-unit-testing) (Uses deprecated hook)
- [Lullabot: A Drupal Module Developer's Guide to SimpleTest](http://www.lullabot.com/articles/drupal-module-developer-guide-simpletest) (Calls drupalEnableModule(), which no longer exists.)

[SimpleTest PHP Library](http://simpletest.sourceforge.net/) (upon which the Drupal SimpleTest module is based)

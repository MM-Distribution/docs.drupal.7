# Ban an IP address

The Ban module or User module allows administrators to ban visits to their site from individual IP addresses.

In Drupal 7, the Ban functionality is part of the System module in Drupal core, rather than being a separate module. In Drupal 8 and later, the Ban module is included in Drupal core as a [separate module](https://www.drupal.org/docs/8/core/modules/ban).

## To ban an IP address

1.  Navigate to **/admin/config/people/ip-blocking**
2.  Enter an IP address (for example, 10.0.0.1).
3.  Click **Add**.

## To remove the ban from an IP address

1.  Navigate to the ban page (see above).
2.  Beside an IP address, click **Delete**.

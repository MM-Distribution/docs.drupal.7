# Managing users in Drupal 7

Drupal 7 core allows you the ability to assign a user one or more *roles*, and to have different *permissions* then assigned to each role. By default, a Drupal user will include values like *username*, *status*, timezone, etc, however you can also with the help of Drupal's [Field API](https://api.drupal.org/api/drupal/modules%21field%21field.module/group/field/7.x) add your own custom fields to your user accounts.

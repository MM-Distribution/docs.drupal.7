# Sub Theme - Inheritance Summary

In the previous section, we understood how a sub theme is created along with inheritance of various properties. The table below summarises the inheritance properties.

|                                                                                                    |           |
|----------------------------------------------------------------------------------------------------|-----------|
| Property                                                                                           | Inherited |
| CSS, JS, Templates(.tpl.php) files, theme and preprocess functions from Template.php & Screenshot. | YES       |
| Regions, Features, Theme Settings, Core Version, Logo, Favicon & Color module support.             | NO        |
